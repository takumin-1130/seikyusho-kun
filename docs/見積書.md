# 見積書

請求書と同じ使い勝手で見積書を出し、受注したらそのまま請求書に変換するための機能です。

発行者情報・振込先・取引先・デザインは請求書の設定をそのまま使います。
見積書のために別途セットアップすることはありません。

---

## 出す

```bash
seikyusho-kun mitsumori
```

対話で「宛先 → 名目 → 金額 → 有効期限」を聞かれます。
全部コマンドで書くこともできます。

```bash
seikyusho-kun mitsumori --to "株式会社ABC" \
  --item "撮影一式" --amount 300000 --qty 1 --unit 式 \
  --item "編集費"   --amount 100000 --qty 1 --unit 式
```

必要なのは **宛先・名目・金額** の3つです。
有効期限は既定（発行日から1ヶ月後）が使われます。

---

## 請求書と違うところ

| | 請求書 | 見積書 |
|---|---|---|
| 金額の見出し | お支払金額 / お振込金額 | お見積金額 |
| 日付 | お支払期限 | 有効期限 |
| 振込先 | 載る | **載らない**（まだ支払いの段階ではないため） |
| 源泉徴収 | 設定に従って引く | **引かない**（総額を示すのが通例のため） |
| 番号 | `202610-001` | `Q202610-001`（**別の連番**） |
| 保存先 | `~/Documents/請求書/{年}/` | `~/Documents/見積書/{年}/` |
| 台帳 | `~/.seikyusho-kun/issued.json` | `~/.seikyusho-kun/quotes.json` |

明細の書き方・金額の読み取り・消費税の計算・A4オートフィットは請求書と同じです。

## 見積書だけのオプション

### 有効期限 `--valid`

```bash
seikyusho-kun mitsumori --to "株式会社ABC" --item "撮影一式" --amount 40万 --valid 2ヶ月後
```

`1ヶ月後` `2週間後`（= `14日後`）`翌月末` `2026-11-30` `11月30日` などが通ります。
既定は `config.json` の `quote.validFor`（初期値 `1ヶ月後`）です。

### 諸経費 `--expenses`

交通費・駐車場代・ロケ地使用料などをまとめた行を1行足します。

```bash
--expenses 30000     # 金額で指定
--expenses 10%       # ほかの明細の合計に対する率で指定
```

率で指定したときの端数は、消費税と同じ設定（`tax.rounding`）に従います。
行に出る品名と内訳は `config.json` の `quote.expenseLabel` / `quote.expenseNote` で変えられます。
その見積だけ内訳を変えたいときは `--expenses-note "駐車場代のみ"` を足します。

### 納期 `--delivery`

```bash
--delivery 2026-11-30      # 日付として読めれば「2026年11月30日」と表示
--delivery "ご発注後30日"   # 読めなければそのまま表示
```

### 納品形式 `--format`

```bash
--format "MP4 / H.264 / 1920×1080"
```

### 修正回数 `--revisions`

```bash
--revisions "初稿提出後2回まで（3回目以降は別途お見積り）"
```

納期・納品形式・修正回数は「お見積条件」として見積書に出ます。
指定しなかった項目は行ごと出ません。

## 毎回同じ条件を書きたくないとき

`~/.seikyusho-kun/config.json` の `quote` に既定値を書いておくと、
`--format` や `--revisions` を毎回打たなくてよくなります。

```json
{
  "quote": {
    "noPattern": "Q{yyyy}{mm}-{seq:3}",
    "outputDir": "~/Documents/見積書/{year}",
    "fileNamePattern": "見積書_{client}_{no}",
    "greeting": "下記の通りお見積り申し上げます。",
    "notes": ["本見積書の有効期限内にご発注いただいた場合の金額です。"],
    "validFor": "1ヶ月後",
    "expenseLabel": "諸経費",
    "expenseNote": "交通費・駐車場代・ロケ地使用料ほか",
    "revisions": "初稿提出後2回まで（3回目以降は別途お見積り）",
    "deliveryFormat": "MP4 / H.264 / 1920×1080"
  }
}
```

`revisions` と `deliveryFormat` は空文字にすると見積書に出ません。

## 受注したら請求書にする

```bash
seikyusho-kun mitsumori list                           # 出した見積書を確認
seikyusho-kun new --from-quote Q202610-001 --due 月末   # 請求書に変換
```

宛先・担当者・明細（諸経費の行も含む）がそのまま引き継がれます。
打ち直しは不要で、締日だけ決めれば発行できます。

- 挨拶文と備考は**請求書用のもの**に戻ります
- 源泉徴収は、請求書側の設定に従って計算されます
- 変換すると見積書側に「請求済み」と記録され、`mitsumori list` に請求書番号が出ます
- すでに請求済みの見積書を指定したときは警告が出ます（発行自体は止めません）

見積書番号の代わりに取引先名でも引けます。その取引先のいちばん新しい見積書が使われます。

```bash
seikyusho-kun new --from-quote ABC --due 月末
```

一部だけ変えて請求したいときは、`--item` を書くとそちらが優先されます。

```bash
seikyusho-kun new --from-quote Q202610-001 --item "撮影一式（短縮版）" --amount 25万 --due 月末
```

## 見た目を変える

テーマは請求書と共通です。`seikyusho-kun theme use modern` のように切り替えると、
請求書も見積書も同じデザインになります。

構造そのものを変えたいときは、自分のフォルダに書き出して `quote.njk` を編集します。

```bash
seikyusho-kun theme eject plain --as mine
# ~/.seikyusho-kun/templates/mine/quote.njk を編集
seikyusho-kun theme use mine
```

`quote.njk` を置かなかった場合は、同梱の見積書テンプレートが使われます。

## 下書きだけ見たい

```bash
seikyusho-kun mitsumori --to "株式会社ABC" --item "撮影一式" --amount 40万 --html
```

HTMLで出力され、**見積書番号は消費しません**。
レイアウトを試すときや、テンプレートを編集しているときに使います。
